# 台灣公費快篩配發診所分析工具 v2.0

這是一個基於 Python 開發的資料分析工具，旨在處理中華民國各縣市公費快篩配發診所的資料的同時學習資料分析技術。
透過此工具，使用者可以快速進行全國性的數據統計視覺化，並具備強大的多條件資料查詢功能，基於 CLI。

---

## 🚀 技術更新

- **向量化運算 Vectorization**
> 捨棄傳統低效的 `for` 迴圈迭代，改採 Pandas 正規表達式 (Regex) 引擎。  

- **好看的 CLI 交互介面**
> 整合 `Rich` 套件

- **型別自動過濾**
> 自動處理 `NaN` 或數字型欄位（如經緯度），防止搜尋時發生 `AttributeError`。

- **字體備援系統**
> 繪圖時自動偵測環境字體，支援 Windows、macOS 跨平台字體顯示。

## 🛠️ 開發環境與安裝

本專案使用 Python 開發，建議環境為 Python 3.7.* 或以上版本。

---

## ⚙️ 設定檔指南 (config.json)

專案採用**資料解耦**設計，您只需修改 `config.json` 即可適應不同的 CSV 格式：

| 參數 | 用途 | 說明 |
| --- | --- | --- |
| `data_path` | 資料來源 | 指定 CSV 檔案的路徑 |
| `output_fig` | 圖表輸出 | 指定生成的 PNG 檔案名稱 |
| `font_name` | 繪圖字體 | 建議 Windows 使用 `Microsoft JhengHei` |
| `search_columns` | 欄位清單 | 定義搜尋介面要顯示的欄位序號與標題 |

## 📖 操作指引

1. **啟動程式**: 執行 `python analysis.py`。
2. **數據統計 (模式 1)**:
* 執行向量化運算並自動彈出視覺化分佈圖。
* 同步保存高解析度 (300 DPI) 圖表至本地。


3. **資料搜尋 (模式 2)**:
* **單一模式**: 選定特定欄位精準模糊比對。
* **多重模式**: 支援多條件連鎖過濾 (AND Logic)。
