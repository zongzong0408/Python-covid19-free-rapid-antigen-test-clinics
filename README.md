# 台灣公費快篩配發診所分析工具 (v1.1)

這是一個基於 **Python** 開發的資料分析工具，旨在處理中華民國各縣市公費快篩配發診所的資料的同時學習資料分析技術。   
透過此工具，使用者可以快速進行全國性的數據統計視覺化，並具備強大的多條件資料查詢功能，基於 CLI。  

---

## 📂 專案目錄結構

```text
.
├── analysis.py       # 資料分析腳本
├── data.csv          # 診所原始資料
└── README.md         # 專案說明文件
```

---

## ✨ 核心功能

### 1. 診所數量統計分析 (`Statistics`)

* **視覺化圖表**：自動整合全台 22 縣市資料，繪製出直觀的長條圖（Bar Chart）。
* **分佈洞察**：快速掌握各行政區醫療資源的配發密度。

### 2. 進階資料查詢系統 (`Inquire`)

* **單一條件搜尋**：可針對診所名稱、地址、電話或經緯度進行精確比對。
* **多重條件交集 (AND)**：支援多維度篩選（例如：臺北市 + 大安區 + 某關鍵字），實現精準的資料定位。

## 🛠️ 環境需求與安裝

### 系統依賴

本程式開發環境為 **Python 3.7.x**。

### 必要套件

請於終端機（Terminal）執行以下指令以安裝所需應用程式套件：

```bash
pip install pandas matplotlib seaborn numpy
```

### 注意事項

* **編碼宣告**：本程式包含中文字元，執行時請確保檔案首行保有 `# -*- coding: utf-8 -*-` 宣告。
* **資料來源**：請確保同目錄下存在 `data.csv` 檔案，且欄位包含 `City`, `Town`, `Name`, `Address`, `Phone` 等資訊。

---

## 🚀 使用說明

執行主程式：

```bash
python analysis.py
```

進入主選單後，您可選擇以下模式：

| 模式編號 | 功能說明 | 適用情境 |
| --- | --- | --- |
| **(1)** | **診所統計分析** | 產生全台縣市分布圖表 |
| **(2)** | **診所資訊查詢** | 執行單一或多重關鍵字過濾 |
| **(3)** | **結束程式** | 安全退出系統 |
